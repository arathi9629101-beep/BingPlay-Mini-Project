# BingePlay – Streaming Analytics Project

## About the Project

BingePlay is a streaming analytics mini project
developed as part of the Unlox Academy internship.

The project focuses on analyzing streaming platform
data using SQL and Python.

It demonstrates how SQL queries can be used to
retrieve, filter, aggregate, and analyze data
to generate meaningful business insights.

## Project Objectives

- Understand advanced SQL concepts.
- Analyze streaming platform data.
- Retrieve information using SQL queries.
- Perform filtering and sorting operations.
- Use aggregate functions for data analysis.
- Understand customer and streaming data.
- Improve SQL problem-solving skills.
